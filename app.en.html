      Welcome

      A few quick settings

      This tool backs up Notes on this Mac into local text copies, so they are easier to organize and use on the computer. Categories and newly added notes can be synced back to the phone through iCloud, or the phone can be left exactly as it is.

      macOS just said the developer could not be verified. That is because this tool does not carry a paid Apple developer signature, not because anything is wrong with it. macOS says the same about every unsigned program. To be sure, hand the repository to any AI and have it checked: there is a checksum list in the repo, and the source is readable.

      Every step below can be skipped, and skipping them all still leaves the tool fully usable — importing, organizing, exporting and filing back need no configuration. Categories can be changed any time: pick one on the card, drag a card onto a category, or let 💡 Smart sort take a first pass; notes with repeated content go into 📑 Versions as versions of one entry.

      🎈 Quick setup
      This tool organizes notes on this Mac. Phone sync requires the same Apple account on both devices, Notes sync enabled and the notes stored in iCloud.
      Setup is optional and settings can be changed later. Importing, organizing, exporting and undoing moves require no setup.
      Create categories
      Select categories to create them. The description beside each category matters : AI uses it to judge notes. A name such as “Resources” gives little context. Names and descriptions can be edited directly.
      Add more categories (one per line, using Name: This category contains… ）
      Notes containing passwords are blocked by default
      Checks run locally and matched notes are not sent to AI. Protection is on by default, with no configuration needed.
